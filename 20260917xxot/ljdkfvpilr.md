# 常见助孕药物的特点及保存方法

> 更新时间：2026-09-17 (UTC+8)

辅助生殖技术药物助孕的过程包括：降调节-促排卵-诱发排卵-黄体支持，在这个过程中我们会接触到很多药物，下面介绍几种我中心常见助孕药物的特点及保存方法‍。

1、注射用尿促性素

   注射用尿促性素( HMG) 每支含 FSH 和 LH 各 75 国际单位，用于促性腺激素分泌不足所致的原发性或继发性闭经、无排卵性稀发月经所致的不孕症等。

用法

肌肉注射；可单独使用，但多数情况下与促性腺激素释放激素激动剂( GnRH )及 FSH 联合应用。

保存要求

25℃

2、人体绒毛膜促性腺激素

   人体绒毛膜促性腺激素（HCG）主要利用其在排卵中的“扳机”作用，模拟 LH 峰，启动卵子的最后成熟与黄体形成，还可用于黄体支持及改善精液质量、女性黄体功能不全、垂体促性腺激素不足所致的无排卵性不孕症等。

用法

肌肉注射

保存要求

25℃

3、注射用重组人绒促性素

  注射用重组人绒促性素（艾泽）主要用于促排卵，促黄体发育，不孕症、黄体功能不足、功能性子宫出血、隐睾症、男性性腺功能减退症、先兆流产或习惯性流产等。

用法

皮下注射

保存条件

25℃以下

4、注射用尿促卵泡素

注射用尿促卵泡素（丽申宝）主要用于辅助生殖技术超促排卵者及多囊卵巢综合征促排的患者

用法

肌肉注射

保存要求
遮光、密闭，不超过20℃

5、克罗米芬

  克罗米芬( CC )是目前在临床应用最为广泛的一种促排卵药物；价格便宜，服用方便。

用法

口服

保存条件

25℃

6、GnRHa

   促性腺激素释放激素（GnRHa）常规用于 IVF 的控制超促排卵中，可有效防止出现早发 LH 峰，使卵泡发育同步化，改善卵子质量与内膜环境，从而提高妊娠率。常用剂型有喷鼻与肌注两类，后者效果稳定，常用的降调节药物分短效(达必佳0.1mg )与长效(达菲林3.75mg )两种。

用法
皮下注射 ，女性连续使用不应超过6个月。

保存要求
达必佳需要在 2-8℃ 低温保存。                     达菲林25℃。

7、重组人促卵泡激素注射液

  重组人促卵泡激素注射液（果纳芬）主要用于无排卵患者（包括对克罗米芬无反应的多囊卵巢综合征患者）以及体外受精（IVF）、配子输卵管内移植（GIFT）及合子输卵管内移植（ZIFT）患者的超排卵；果纳芬按包装不同分为 75 和 450 国际单位，分别称为“小果”和“大果”。

用法

 皮下注射；根据患者的反应调节剂量。

保存条件
大果需要保存在 2-8℃ 低温保存，开启后需要在 28 天内使用完毕。
特别提醒：

1、请您每天尽可能在相对固定的时间注射，上下波动时间不得超过两个小时；

2、长期注射给药，要经常更换注射部位，并保持局部皮肤的清洁，避免大量出汗或者洗澡水过烫，以免发生注射部位的感染；

3、促排卵期间请不要剧烈运动，突然改变体位或憋尿；

4、您可以选择就近或方便的地方注射；如果您选择在我中心注射，请您注射前凭已缴费的注射单在分诊台背后的注射室注射；

5、切忌药物不能冷冻哦！‍
